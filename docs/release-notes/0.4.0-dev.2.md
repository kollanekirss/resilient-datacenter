# 0.4.0-dev.2 — local network foundation

Development source iteration; no signed release artifact or production-readiness claim.

The Proxmox wizard gains local-network preparation, a private plan-bound setup kit, guided OPNsense policy/DHCP instructions, per-guest static addressing, a guarded separate DNS/time module and bounded client diagnostics. Local service records require no external DNS. The chosen time source and its limitations are explicit. Existing Ubuntu application deployments retain their behavior.

Generation changes no servers. OPNsense and Netplan activation use guided console steps. The DNS/time playbook requires preinstalled packages, verified SSH trust, an explicit matching role-consent file and the intended fresh Ubuntu guest. It never applies host networking or flushes unrelated firewall tables. Client probe failures return nonzero; passing probes are not application readiness or proof of UTC/isolation.

Read [local network setup](../portable-local-network.md) and the generated START-HERE guide. Real OPNsense/Proxmox and guarded-playbook deployment acceptance, NGINX/application access, offline reconstruction and relocation remain outstanding. Current validation evidence is recorded in [validation status](../validation-status.md).
