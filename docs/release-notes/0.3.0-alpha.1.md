# Experimental self-hosted service kit

This prerelease includes guided personal, institutional and regional plans; independent Headscale networking and additional DERP locations; Matrix/Element and Nextcloud on separate Ubuntu VMs; local accounts; trusted TLS lifecycle; encrypted SFTP/Restic backups and fenced fresh-node recovery; restricted bilateral regional exchange; separate operational status; and the explicitly reviewed application upgrade transitions.

Managed Ubuntu network clients disable upstream diagnostic-log uploads while retaining local logs. Independently installed user-device clients require their own configuration.

Target: fresh Ubuntu 24.04 amd64 with systemd. A preparation computer may run the planning tools. The artifact contains exact source, a Linux amd64 DERP executable, its build metadata, upstream license notices and a SHA-256 manifest. GitHub attestations bind every asset to this tagged source and release workflow. Fetching does not install or execute them.

Read README.md, docs/prerequisites.md and docs/product-start.md before deployment. Use docs/releases.md to verify the download against the full source commit below. This is the current product source; the older 0.2.0-alpha.1 artifact predates application packages.

Experimental only: automated Ubuntu acceptance does not establish physical site separation, public-provider issuance, institutional security approval or unfamiliar-user usability. Those require the site acceptance worksheet. Private DNS, router configuration, SSO, ARM, arbitrary application versions, automatic failover and uninterrupted relocation are not provided. Restore requires independent fencing and saved recovery credentials. Backup writers can delete their repository; encryption is not immutability.

Review docs/validation-status.md and the exact source checks for bounded evidence. A supported release waits for the remaining real-site and human acceptance.
